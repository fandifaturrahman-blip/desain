# Promo Awal Desember 2026 — STEPAT

Artwork Instagram berukuran 1080 × 1350 px, dibuat sebagai SVG vektor agar dapat dibuka dan diedit di Adobe Illustrator.

## File
- `promo-awal-desember-2026.svg` — master vektor yang dapat diedit.

## Ekspor JPG dan PDF melalui Adobe Illustrator
1. Unduh SVG dari repositori ini dan buka dengan Adobe Illustrator.
2. Jika font Arial tidak tersedia, pilih font sans-serif tebal yang serupa. Logo dan ilustrasi botol pada file ini adalah grafis ilustratif, bukan foto produk asli.
3. **JPG:** pilih `File > Export > Export As...`, pilih JPEG, gunakan artboard, kualitas maksimum, dan resolusi 300 ppi.
4. **PDF:** pilih `File > Save a Copy...` atau `Save As...`, pilih Adobe PDF, preset `High Quality Print`, dan aktifkan `Use Artboards`.

Catatan: promo dari referensi November disesuaikan menjadi promo awal bulan dengan periode **1–10 Desember 2026**. Harga, benefit, dan ketentuan tetap perlu dikonfirmasi sebelum dipublikasikan. SVG ini sudah siap diedit; JPG/PDF dapat diekspor dari Illustrator agar hasil raster dan PDF sesuai kebutuhan cetak atau Instagram.
